# PosWeb Backend - Dataplus 
Sistema de ventas

## Requisitos

- Node.js >= 18.12.0
- pnpm >= 8.0.0

## Instalación

### 1. Instalar/Actualizar Node.js

Si usas nvm:
```bash
nvm install 18.15.0
nvm use 18.15.0
```

### 2. Instalar pnpm

```bash
npm install -g pnpm
```

### 3. Instalar dependencias

```bash
pnpm install
```

## Scripts disponibles

- `pnpm dev` - Iniciar servidor en modo desarrollo
- `pnpm build` - Compilar TypeScript
- `pnpm start` - Iniciar servidor de producción
- `pnpm test` - Ejecutar pruebas
